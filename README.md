### Short Summary
- The way data is organized and stored is one of the main distinctions between relational databases (eg. MySQL) and non-relational databases like MongoDB. Whereas MongoDB stores data as adaptable JSON-like documents that support variable fields and nested structures, MySQL arranges data into fixed tables with predetermined schemas. I think that retail pharmacies could benefit from using non-SQL database like MongoDB. Prescription records with various drug combinations, dose forms, and refill histories might be effectively stored in a pharmacy system utilizing MongoDB without requiring a database schema redesign.
